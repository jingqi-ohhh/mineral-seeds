# Mineral Seeds（矿物种子）

在耕地上种植矿物种子，收获矿物！

## 支持的矿物（12种）

煤炭 · 铁 · 金 · 铜 · 红石 · 青金石 · 钻石 · 绿宝石 · 下界石英 · 远古残骸 · 下界合金 · 萤石

## 合成配方

1个矿物（中心）+ 8个小麦种子（围绕）= 8个矿物种子

## 玩法

1. 合成矿物种子
2. 在耕地上右键种植
3. 等待4个生长阶段（骨粉可催熟）
4. 收获1-3个对应矿物

## 版本支持

- Minecraft 1.21.1 + Fabric
- Minecraft 1.20.1 + Fabric

## 构建

```bash
./gradlew build
```

JAR 文件在 `build/libs/` 下。
